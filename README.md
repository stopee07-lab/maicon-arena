# MAICON 로컬 경기장

Mac에서 혼자 실행하는 대회 준비용 시뮬레이터다. 3D 경기장, UGV 6대, 드론 영상, 운영자 제어, 참가자 코드 편집, 사진 라벨링·모델 학습, 경기 실행·녹화를 포함한다.

## 실행

검증 환경은 Apple Silicon Mac, Python 3.14다. Python과 FFmpeg를 준비한 뒤:

```sh
./setup.sh
./start.command
```

브라우저에서 <http://127.0.0.1:8887>을 연다. 다른 포트가 필요하면 `./start.command --port 8890`을 사용한다. 서버는 기본적으로 내 컴퓨터에서만 접속할 수 있다.

## 연습 순서

1. 코드 화면에서 `workspace/team_node.py`를 수정하고 버전을 저장한다.
2. 모델 화면에서 제공 모델을 선택하거나, 사진을 수집·라벨링한 뒤 새 모델을 학습한다.
3. 실행 화면에서 본선 모의 경기와 적용할 코드·모델을 선택한다.
4. 주최측 준비·시작·정지·보고 흐름을 실행하고, 카메라와 제출 결과를 확인한다.
5. 녹화는 실행 화면의 녹화 시작/종료 버튼으로 저장한다.

JupyterLab도 같은 `workspace/` 파일을 편집한다. 파일을 저장한 뒤 웹 화면에서 새 코드 버전을 적용해야 실행 프로세스가 바뀐다.

## 파일

- `server.py`, `engine.py`: 운영자·참가자 API와 경기 상태
- `physics*.py`, `arena_layout.py`, `web/`: 물리·센서·3D 화면
- `workspace/`: 수정할 참가자 프로그램
- `training/`: 데이터·학습·평가
- `models/`: 예시 사진 6종으로 추가 학습한 모델과 해시
- `tests/`: 기능 검증
- `reports/`: 미션별 누적 시험 보고서와 통합 데이터
- `ros2/`: 별도 Ubuntu/ROS 환경 연결 파일

인증값과 실행 기록은 첫 실행 때 `data/`에 새로 생성된다. 이 폴더와 개인 API 키는 Git에 포함하지 않는다. 원시 대용량 카메라 기록은 실험을 수행한 프로젝트에 보관한다.

## 확인 범위

이 저장소는 제공 자료를 바탕으로 만든 로컬 모의 환경이며 주최측 공식 소프트웨어가 아니다. 모델은 같은 예시 사진을 다른 각도·거리·조명으로 렌더링한 영상에서 검증했다. 실제 UGV와 실제 카메라 검증을 뜻하지 않는다. 점수·실패·수정 내역은 `reports/`의 미션별 보고서를 기준으로 본다.
