# MAICON 팀 연습실

로봇 경기장을 내 컴퓨터에서 열어 보고, 코드를 시험하고, 결과를 확인하는 프로그램입니다.

## 처음 시작하기

1. **Python 3.12 (64비트)**를 설치합니다. Windows는 설치 화면의 **Add python.exe to PATH**를 체크합니다.
2. [최신 배포 파일](https://github.com/stopee07-lab/maicon-arena/releases/latest)에서 Windows ZIP 또는 Linux TAR.GZ를 받아 **압축을 풉니다**. Git을 쓰면 `git clone`해도 됩니다.
3. 아래 시작 파일을 엽니다. 처음에는 설치로 몇 분 걸리며 인터넷이 필요합니다.

| 내 컴퓨터 | 열 파일 |
| --- | --- |
| Windows | **start.cmd** 더블클릭 |
| Mac | **start.command** 더블클릭. 안 열리면 이 폴더의 터미널에서 `bash start.command` |
| Linux 클라우드 | [서버 접속 안내](docs/platforms.md#ubuntu-클라우드-서버)를 따라 실행 |

처음에는 **코드·학습 → 코드 수정 → 실행할 곳: 경기 → 동작: 인식 + 행동 코드 → 제공 모델 선택 → 현재 코드 적용·실행** 순서로 시작합니다. 모델·코드가 준비된 다음부터는 경기 화면의 **코드·경기장 실행**으로 시작합니다. 물리 경기장과 로봇을 함께 준비하므로 시뮬레이터를 따로 켤 필요가 없습니다.

경기 화면은 전술 상황판 배치입니다. 같은 화면에서 일시정지·재개·초기화, 점수·로봇 상세, 배속과 녹화를 사용합니다. 관전자 화면은 읽기 전용이므로 조작할 때는 **운영 화면**으로 들어갑니다. 목표 배속 1×/5×/20×와 실제 달성 속도를 구분하며, 배속은 센서·제어 조건이 달라지는 별도 시뮬레이션 조건입니다.

**이미지·정답** 화면에는 제공 모델 학습에 썼던 원본 720장과 정답 라벨이 처음 실행할 때 등록됩니다(학습 480 / 검증 120 / 시험 120). 예시 사진 6장을 변형한 합성 자료로 실제 카메라 검증 자료가 아닙니다. 원본 해시와 분할은 보존하며 기존 데이터는 덮어쓰지 않습니다.

- **끝내기:** **실행 중인 터미널 창을 닫으면 서버와 로봇도 종료됩니다.** Ctrl+C도 사용할 수 있습니다.
- **다음부터:** 같은 시작 파일을 다시 열면 됩니다. 실행 창은 켜 둡니다.
- **화면이 안 뜨면:** 실행 창의 오류를 확인하고 브라우저에서 `http://127.0.0.1:8887`을 엽니다.
- **화면:** `http://127.0.0.1:8887/index.html?mode=mission`이 경기 운영 화면입니다. 5번 경기·녹화에서도 같은 화면으로 연결됩니다.

## 팀원이 같은 소스로 사용할 수 있나요?

기본 경기장·로봇 코드는 같은 소스를 사용합니다. **각 OS에서 처음 설치를 따로 해야 하며 Mac의 가상환경(`training/.venv`)을 복사하면 안 됩니다.** Windows 경로와 Linux 서버 렌더링은 실행기가 구분합니다.

실제 검증 범위, Linux SSH 접속, GPU·ROS·JupyterLab·녹화의 차이는 [OS별 안내](docs/platforms.md)에 있습니다. [GitHub Actions](https://github.com/stopee07-lab/maicon-arena/actions/workflows/platform-smoke.yml)에서 Windows/Linux 설치·카메라·참가 코드 이동과 Mac 설치·import 검사를 수행합니다. CI 통과와 팀원의 실제 그래픽 드라이버·브라우저·UGV 검증은 구분합니다.
