# MAICON 팀 연습실

로봇 경기장을 내 컴퓨터에서 열어 보고, 코드를 시험하고, 결과를 확인하는 프로그램입니다.

## 처음 시작하기

1. **Python 3.12 (64비트)**를 설치합니다. Windows는 설치 화면의 **Add python.exe to PATH**를 체크합니다.
2. 이 저장소에서 **Code → Download ZIP**을 누르고 **압축을 풉니다**. Git을 쓰면 `git clone`해도 됩니다.
3. 아래 시작 파일을 엽니다. 처음에는 설치로 몇 분 걸리며 인터넷이 필요합니다.

| 내 컴퓨터 | 열 파일 |
| --- | --- |
| Windows | **start.cmd** 더블클릭 |
| Mac | **start.command** 더블클릭. 안 열리면 이 폴더의 터미널에서 `bash start.command` |
| Linux 클라우드 | [서버 접속 안내](docs/platforms.md#ubuntu-클라우드-서버)를 따라 실행 |

브라우저가 열리면 **코드 수정 → 실행할 곳: 경기 → 동작: 인식 + 행동 코드 → 제공 모델 선택 → 현재 코드 적용·실행** 순서로 시작합니다. 이 버튼이 물리 경기장과 로봇을 함께 켭니다. **시뮬레이터 켜기를 먼저 누를 필요는 없습니다.**

**이미지·정답** 화면에는 제공 모델 학습에 썼던 원본 720장과 정답 라벨이 처음 실행할 때 등록됩니다(학습 480 / 검증 120 / 시험 120). 예시 사진 6장을 변형한 합성 자료로 실제 카메라 검증 자료가 아닙니다. 원본 해시와 분할은 보존하며 기존 데이터는 덮어쓰지 않습니다.

- **끝내기:** **실행 중인 터미널 창을 닫으면 서버와 로봇도 종료됩니다.** Ctrl+C도 사용할 수 있습니다.
- **다음부터:** 같은 시작 파일을 다시 열면 됩니다. 실행 창은 켜 둡니다.
- **화면이 안 뜨면:** 실행 창의 오류를 확인하고 브라우저에서 `http://127.0.0.1:8887`을 엽니다.
- **화면:** 공유 개선 전 UI를 그대로 복원했습니다. 새 시작 화면·기록 비교 화면·통신 확인 화면은 포함하지 않습니다.

## 팀원이 같은 소스로 사용할 수 있나요?

기본 경기장·로봇 코드는 같은 소스를 사용합니다. **각 OS에서 처음 설치를 따로 해야 하며 Mac의 가상환경(`training/.venv`)을 복사하면 안 됩니다.** Windows 경로와 Linux 서버 렌더링은 실행기가 구분합니다.

실제 검증 범위, Linux SSH 접속, GPU·ROS·JupyterLab·녹화의 차이는 [OS별 안내](docs/platforms.md)에 있습니다. Windows에서 실제 구동하기 전까지 완전한 동작을 확인했다고 보지는 않습니다.
