# 시연 사용성 복구 Implementation Plan

Goal: 기존 UI에서 공유 데이터, 모델, 참가자 제어기를 연결하고 반복 가능한 사용 순서를 검증한다.
Architecture: UI는 c1c0ad5와 동일하게 보존. 원본 기록/모델은 보존. 데이터 설치, 센서 주행, 기본 정책 발사를 독립 수정하고 통합 검사한다.
Tech Stack: Python, MuJoCo, existing web UI.

- [x] 학습 원본 데이터의 소재와 공유 크기 확인, 원본 해시를 유지하는 설치 추가. 기존 사용자 데이터 덮어쓰기 금지.
- [x] 참가자 센서 정지 원인을 저장 기록으로 재현. 결측을 빈 공간으로 취급하지 않고 관측 근거로 회복. 회귀검사 후 반복 실행.
- [x] 기본 정책은 거리 반사만으로 발사 금지. 정책 버전을 변경하여 이전 상대 조건과 구분.
- [x] 기존 버튼으로 신규 설치→데이터 표시→모델 연결→주행→종료 검증. UI 파일 변경 금지.
- [x] 설명서 실행 순서를 검증된 동작으로 수정. ZIP/BUNDLE 갱신 및 이전본 보존.
- [x] 실험 ID, 코드/모델 해시, 입력/명령/결과/실패/영상 유무 보존. 실물 성능 또는 미시험 OS 성공 주장 금지.
