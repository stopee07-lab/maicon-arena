# 경기 화면 복원과 누적 지연 정지 수정 — 2026-11-17

사용자가 지정한 기존 전술 상황판 배치를 기본 경기 운영 화면으로 복원했다. 5번 경기·녹화 진입은 `/index.html?mode=mission`으로 연결하며 운영 제어는 이 화면 한 곳에서 제공한다. 관전자 주소는 읽기 전용이고 운영 화면으로 돌아가는 링크를 표시한다.

## 원인과 변경

실제 8897 서버는 경기 27.8초에서 paused=true였으나 물리 엔진·참가 코드 모두 정상 연결 중이었다. `physics_lag` 이벤트와 누적 지연 2.169초가 확인됐다. 이전 물리 실행 루프가 벽시계와의 누적 차이를 메우다가 2초 이상 밀리면 영구 일시정지시킨 것이 원인이다.

새 실행 루프는 0.05초 물리 샘플을 유지하고 요청 배속에 맞춰 대기한다. 처리 시간이 길면 실제 달성 속도가 낮아지며, 과거 시간 차이를 따라잡기 위한 명령 재생이나 누적 지연에 의한 강제 정지를 하지 않는다. 실제 연결 끊김 감지와 사용자의 일시정지는 유지한다. 브라우저 3D 렌더링은 최대 30FPS이며 숨겨진 탭은 그리기를 쉰다.

목표 배속 1×/5×/20×를 복원하고 실측 배속을 표시한다. 경기 시계만 곱하지 않고 MuJoCo의 고정 간격 물리 계산과 채점을 함께 진행한다. 장비 성능에 따라 요청 배속에 못 미칠 수 있다.

**배속은 별도 시뮬레이터 실험 조건이다.** 5×/20×는 최대 5개 샘플을 묶어 처리하며 카메라·외부 참가 코드의 반응 비율이 1×와 달라진다. 벽시계 기반 참가 코드의 대기 시간도 달라진다. 배속 성적을 1× 또는 실제 장비 성능과 직접 비교하지 않는다. 사용자 참가 코드와 모델은 수정하지 않았다.
