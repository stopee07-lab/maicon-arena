# 공유·시연 복구 검증 (2026-11-16)

## 범위

UI 파일은 c1c0ad5와 동일하게 유지했다. 기존 Mac 시작 파일과 팀원용 시작 파일을 사용한다. 코드 수정 화면의 '현재 코드 적용·실행'이 물리 엔진과 모델, 참가자 코드를 함께 시작하므로 별도 엔진 시작 단계를 설명서에서 제거했다.

## 변경

- 모델과 연결된 원본 학습 자료 720장(480/120/120) 및 라벨을 배포에 포함했다. 이미지·라벨·분할·데이터 해시를 보존하고 각 컴퓨터의 data.yaml만 다시 만든다. 기존 사용자 데이터는 덮어쓰지 않는다.
- 센서 결측 보완은 실제 원본 측정의 촬영 시각과 위치를 확인하고, 오래된 관측보다 최신 유효 관측을 우선한다. 원본 나이와 이동 불확실성을 반영한다. 전면 센서가 없거나 장애물이 가까우면 정지한다.
- 앞쪽 직진이 확인됐을 때 작은 방향 보정에 필요한 주변 관측이 부족하면 회전을 생략할 수 있다. 후진·큰 회전은 완화하지 않았다.
- 과거 관측의 불확실성으로 줄인 거리값을 새 앞 장애물로 오해해 후진하던 결함을 수정했다. 불확실하면 새 관측을 기다리고, 원본 센서가 앞 장애물을 확인했을 때만 회피를 시작한다.
- 기본 시연 정책은 정체를 모르는 거리 반사만으로 발사하지 않는다. 시각적 적 식별기가 없는 이 정책의 자동사격은 보류 상태다. 수동 발사와 참가자 시설 표적 조준 경로는 별도다. 상대 정책 버전은 sensor-five-roles-v4-no-blind-fire로 바뀌었으므로 이전 v3 경기 점수와 직접 비교하지 않는다.

## 검증 방법

별도 빈 폴더에 공유 소스만 복사하고 실제 Mac Python/MuJoCo와 화면을 표시하지 않는 Chrome으로 기존 버튼을 눌렀다. 각 실행은 동일한 무작위 조건 번호 20261113, mild 센서, 동일 모델, 동일 상대 v4를 사용했다. 초기 데이터 표시, 모델 선택, 현재 코드 적용·실행, 카메라·위치 변화, 전체 정지, 서버 종료를 확인한다.

시작 구역 통과 기준은 진단용 실제 위치 x>=3.4m로 지정했다. 이 위치와 관리자 정보는 참가자 코드 입력에 넣지 않았다. 각 150초 기능 시험은 의도적으로 중단한 경기로, 완주 점수나 승률이 아니다. 수정 중 실패·중단한 후보도 원본과 함께 보존했다.

## 기록과 제한

통합 기록 ID: demo-repair-20261116-182155. 실행별 센서·판단·명령·API 제출·모델/코드 해시와 결과는 이 기록 및 그 아래 fresh-install/data에 보존한다. 영상은 녹화하지 않았고 화면 캡처만 저장했다.

센서 보완의 0.75초, 0.025m, 0.10rad 및 접근 속도 0.4m/s는 로컬 보정 가정이다. 서로 다른 시계는 같은 호스트에서 촬영한 시각과 실제시간 1배를 기준으로 연결했다. 해당 정보가 없는 ROS 연결에서는 결측 보완을 보장하지 않는다. 실제 UGV/카메라/ROS/대회 조건, Windows 및 Linux x86_64 구동은 이번에 검증하지 않았다.

720장은 제공 예시 사진 6장을 변형한 합성 자료다. 다른 원본 사진과 실물 인식 성능을 입증하지 않는다. 주행 개선은 전체 임무의 높은 점수나 실전 전략 최적성을 의미하지 않는다.
