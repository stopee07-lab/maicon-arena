경기를 종료하고 참가 코드를 정지한 뒤 변경하세요. 저장하면 경기장이 초기화됩니다. 규칙은 11월 12일 자료·답변 기준 잠정값이며, 현장 안내 후 수정해야 합니다.

1. 경기장과 센서

오차 크기·수광부 치수·노면 계수는 실측 전 가정입니다. 상대의 관측과 명령도 경기 기록에 저장합니다.

2. 참가 코드 연결

자유연습은 수정 → 재배포 → 재시험을 반복할 수 있습니다. 저장한 버전으로 실행하므로 편집한 파일이 실행 중 코드에 즉시 섞이지 않습니다.

3. M1·M6 텍스트 LLM

이미지와 관리자 정답은 보내지 않습니다. M1 지시문, M6 관측 내용·측정 시각·신뢰도만 텍스트로 전달합니다. 키는 이 Mac에 권한 600 파일로 저장하며 화면·실험 기록에는 표시하지 않습니다.

연결 중

판정과 결과를 볼 때

한 경기 점수와 전체 대회 환산 점수는 구분합니다. 예시 사진 6장을 여러 각도로 촬영한 학습 결과는 새로운 실제 사진 인식 성능이 아닙니다. 다른 원본을 가져와 이미지·정답 화면의 원본 그룹 분리 평가를 사용하세요.

이 환경은 심판 서버의 복제품이나 실물 교정값이 아닙니다. 공식 수광 위치, 렌즈·조명, 물리 계수와 제공 LLM 연결은 현장에서 확인합니다.
