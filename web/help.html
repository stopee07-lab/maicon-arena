이 웹 화면이 프로그램의 조종판입니다.
뒤에서 계산하는 실행 창도 함께 켜 두세요.

1. 프로그램 켜기

  1. 받은 ZIP 파일의 압축을 먼저 풉니다.
  2. Windows는 start.cmd, Mac은 start.command를 엽니다.
  3. 설치가 끝날 때까지 기다립니다. 브라우저에 시작하기 화면이 열립니다.

Python 3.12가 먼저 필요합니다. Windows 설치 중에는 “Add python.exe to PATH”를 체크하세요. Linux 서버는 저장소의 docs/platforms.md를 따라 하세요.

2. 처음 연습하기

  1. 시작하기 화면의 예제 결과 보기를 누릅니다. 아래 시간 막대를 움직이면 저장된 로봇 경로를 볼 수 있습니다.
  2. 시작하기로 돌아와 경기장 열기를 누릅니다. 3D 경기장과 카메라가 나오면 성공입니다.
  3. 다시 시작하기에서 로봇 시험하기를 누릅니다. 처음에는 모델과 ‘물체를 보고 움직이기’를 그대로 두세요.
  4. 로봇의 카메라와 행동을 봅니다. 끝낼 때 전체 정지를 누릅니다.

예제 보기는 과거 기록입니다. 경기장 열기와 로봇 시험하기는 지금 컴퓨터에서 모의실험을 실행합니다.

3. 기록 남기기

  1. 경기·녹화 화면에서 기록 파일 저장을 누릅니다.
  2. 기록 비교에서 저장한 JSON 파일을 엽니다. 다른 기록도 열면 나란히 볼 수 있습니다.
  3. 팀원에게는 이 JSON과 어떤 코드를 썼는지 함께 알려 주세요.

자유연습이나 중간에 멈춘 기록은 완주 성적이 아닙니다. 조건·상대·코드가 다른 결과를 점수만 보고 비교하지 마세요.

막혔을 때

시작 파일이 안 열려요

Python 3.12 설치를 확인하세요. Mac은 터미널에서 받은 폴더로 이동한 뒤 bash start.command를 입력할 수 있습니다. Windows는 압축 안에서 실행하지 말고 먼저 풀어 주세요.

웹 화면이 안 떠요

실행 창을 켜 둔 채 브라우저 주소에 http://127.0.0.1:8887을 입력하세요. 이미 사용 중인 번호라는 오류는 이전 실행 창을 확인하세요. 번호 변경은 docs/platforms.md에 있습니다.

로봇이 안 움직여요

‘로봇이 할 일’이 물체를 보고 움직이기인지 확인하고 전체 정지 → 로봇 시험하기로 다시 누르세요. 오류 문구를 그대로 팀원에게 알려 주세요. 본 경기의 보고 오류는 ‘통신 확인’에서 볼 수 있습니다.

조건 번호(시드)가 뭔가요?

같은 시험 조건을 다시 만들 때 쓰는 번호입니다. 1회차·2회차 같은 실행 횟수가 아닙니다. 같은 번호로 여러 번 시험할 수 있습니다. 센서·상대 설정도 같아야 비교하기 좋습니다.

완전히 끝내려면?

화면의 전체 정지를 누른 뒤 실행 창에서 Ctrl+C를 누릅니다. 웹 화면만 닫으면 뒤의 프로그램이 계속 실행될 수 있습니다.

코드·학습·ROS도 해야 하나요?

첫 연습에는 필요 없습니다. 제공된 코드와 모델을 쓰세요. 익숙해지면 ‘코드 바꾸기’나 ‘모델 학습하기’를 엽니다. JupyterLab과 ROS는 선택 기능입니다.
