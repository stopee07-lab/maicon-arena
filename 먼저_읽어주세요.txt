MAICON 처음 사용하기

1. Python 3.12를 설치하세요.
   Windows에서는 Add python.exe to PATH를 체크하세요.
2. 받은 ZIP의 압축을 푸세요.
3. Windows: start.cmd / Mac: start.command를 여세요.
   처음 설치에는 인터넷과 몇 분의 시간이 필요합니다.
4. 브라우저가 열리면 예제 결과 보기를 눌러 보세요.
5. 시작하기로 돌아와 경기장 열기 → 로봇 시험하기를 누르세요.
6. 끝나면 전체 정지를 누르고 실행 창에서 Ctrl+C를 누르세요.

화면이 안 뜨면: 실행 창을 켜 두고 http://127.0.0.1:8887 접속
Mac 더블클릭이 안 되면: 받은 폴더의 터미널에서 bash start.command
Linux 서버 사용법: docs/platforms.md
더 자세한 설명: 프로그램 위쪽의 사용법

같은 소스를 사용하되 OS마다 설치는 새로 합니다.
Windows와 Linux x86_64의 실제 실행은 아직 확인 전입니다.
실제 로봇·대회 성능과 모의 경기 점수는 별개입니다.
