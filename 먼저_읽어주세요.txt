MAICON 팀 시연 — 이 순서로 시작하세요

[내 Mac의 개선본]
바탕화면 → Projects → AI 경진대회 → 공유개선 → 개선본_열기.command

[팀원이 받은 ZIP]
1. Python 3.12 설치 (Windows는 Add python.exe to PATH 체크).
2. ZIP 압축을 풀고 Windows: start.cmd / Mac: start.command 실행.
   처음 한 번은 인터넷 연결과 설치 시간이 필요합니다.

[웹페이지가 열리면]
1. 왼쪽 '코드 수정'을 누르세요.
2. 실행할 곳: '경기', 동작: '인식 + 행동 코드'를 선택하세요.
3. 인식 모델: '추가 학습 · 예시 사진 6장…'을 선택하세요.
4. '현재 코드 적용·실행 →'을 한 번 누르고 실행 확인을 기다리세요.
   경기장·모델·로봇이 함께 시작되고 경기 화면으로 이동합니다.
   '시뮬레이터 켜기'를 미리 누를 필요는 없습니다.
5. 끝낼 때 '전체 정지'. 프로그램까지 닫으려면 실행한 터미널 창을 닫으세요.

[학습 자료 보여주기]
왼쪽 '이미지·정답' 화면에서 '예시 사진 6장 · 시야각·거리·조명·약한 흐림' 선택.
720장: 학습 480 / 검증 120 / 시험 120. 기존 학습 원본과 정답 라벨입니다.
예시 사진을 변형한 합성 자료이며, 실제 로봇 카메라 사진은 아닙니다.
고정된 원본은 수정하지 말고, 수정본을 만들어 재학습하세요.

[직접 운전하려면]
전체 정지 후 '경기·녹화' 화면에서 '자유연습'과 '시뮬레이터 켜기' 사용.
자동 행동 코드가 실행 중이면 수동 주행 버튼이 잠깁니다.

[문제가 생기면]
실행 중인 터미널에 표시된 '경기장' 주소로 접속하세요.
내 개선본은 8897, 팀원용 기본 실행은 8887 포트입니다.
Mac 더블클릭이 안 되면 받은 폴더의 터미널에서 bash start.command.
Linux 서버 설치: docs/platforms.md. 상세: README.md.

기본 상대 로봇은 시각적 적 식별기가 없어 자동사격을 보류합니다.
거리만 보고 벽·상자에 발사하지 않습니다. 수동 발사는 별도입니다.
인식 모델은 물체 분류용이며, 주행·회피는 별도 행동 코드입니다.
모의 시연 확인과 실제 대회 성능 검증은 별개입니다.
Windows / Linux x86_64 실제 실행은 미검증입니다.
